ขั้นตอนสร้างลิงก์เชื่อมต่อ Google Drive (ใช้เวลา 2 นาที):
  1. ไปที่ script.google.com และกด + โครงการใหม่ (New Project)
  2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดด้านล่างนี้ลงไปแทน จากนั้นกดปุ่ม 💾 บันทึก
  3. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)
  4. เลือกประเภทเป็น เว็บแอป (Web app) > ตั้งค่าผู้มีสิทธิ์เข้าถึงเป็น ทุกคน (Anyone) > กด ทำให้ใช้งานได้ (Deploy) และกดอนุญาตสิทธิ์เข้าถึง Google Drive
  5. คัดลอก Web app URL มาวางในช่องด้านบนนี้ได้เลย (เมื่อเปิดไฟล์เว็บนี้บนมือถือหรือคอมพิวเตอร์เครื่องอื่น ให้นำ URL เดิมมาใส่ ข้อมูลจะตรงกันทันที)
const FILE_NAME = "water_quality_10_stations.json";

function doGet(e) {
  const files = DriveApp.getFilesByName(FILE_NAME);
  let data = [];
  if (files.hasNext()) {
    const content = files.next().getBlob().getDataAsString("UTF-8");
    data = JSON.parse(content || "[]");
  }
  return ContentService.createTextOutput(JSON.stringify({ status: "ok", records: data }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  const payload = JSON.parse(e.postData.contents);
  const jsonStr = JSON.stringify(payload.records || [], null, 2);
  const files = DriveApp.getFilesByName(FILE_NAME);
  if (files.hasNext()) {
    files.next().setContent(jsonStr);
  } else {
    DriveApp.createFile(FILE_NAME, jsonStr, MimeType.PLAIN_TEXT);
  }
  return ContentService.createTextOutput(JSON.stringify({ status: "saved", count: (payload.records || []).length }))
    .setMimeType(ContentService.MimeType.JSON);
}

ค่าความเค็ม (Sal): ไม่เกิน 0.50 กรัม/ลิตร (ppt)
ค่าความนำไฟฟ้า (EC): น้อยกว่า 1,000 ไมโครโม/ซม.

🌊 2. น้ำกร่อย (Brackish Water)

ค่าความเค็ม (Sal): มากกว่า 0.50 ถึง 30.00 กรัม/ลิตร (ppt)
ค่าความนำไฟฟ้า (EC): 1,000 – 45,000 ไมโครโม/ซม.
ค่าของแข็งละลายน้ำ (TDS): 650 – 30,000 มก./ลิตร
ลักษณะและการใช้ประโยชน์: มักเกิดบริเวณปากแม่น้ำหรือช่วงน้ำทะเลหนุน ไม่ควรนำมาดื่มหรือรดน้ำพืชทั่วไป แต่เหมาะสำหรับเพาะเลี้ยงสัตว์น้ำกร่อย เช่น กุ้งขาว ปลากะพงขาว ปูทะเล

⚓ 3. น้ำทะเล (Seawater)

ค่าความเค็ม (Sal): มากกว่า 30.00 กรัม/ลิตรขึ้นไป (เฉลี่ย ~35.00 ppt)
ค่าความนำไฟฟ้า (EC): มากกว่า 45,000 ไมโครโม/ซม.
ค่าของแข็งละลายน้ำ (TDS): มากกว่า 30,000 มก./ลิตร
ลักษณะและการใช้ประโยชน์: มีความเค็มสูงมาก ใช้สำหรับระบบนิเวศทางทะเล การทำนาเกลือ และการเพาะเลี้ยงสัตว์น้ำเค็มชายฝั่ง ห้ามใช้รดพืชหรืออุปโภคบริโภคโดยตรง

เกณฑ์คุณภาพน้ำที่เหมาะสมต่อการดำรงชีวิตประจำวัน การเพาะปลูก และการเลี้ยงสัตว์

🏡 1. การใช้ชีวิตประจำวัน (อุปโภค-บริโภค)

  • pH: 6.50 – 8.50 (ไม่เป็นกรดกัดกร่อนท่อ หรือด่างจนระคายเคืองผิวหนัง)
  • ความเค็ม (Sal) / TDS: ควรเป็นน้ำจืด (Sal ≤ 0.50 ก./ล. และ TDS ≤ 500–600 มก./ล. เพื่อไม่ให้มีรสกร่อยหรือเกิดตะกรันในเครื่องใช้ไฟฟ้า)
  • ออกซิเจนละลายน้ำ (DO): ควรสูงกว่า 4.00 มก./ลิตร น้ำจะใสสะอาด ไม่มีกลิ่นเหม็นเน่า สามารถนำไปผ่านระบบกรองและฆ่าเชื้อเพื่อใช้อุปโภคบริโภคได้

🌱 2. การเพาะปลูกและเกษตรกรรม

  • pH: 6.00 – 8.00 (ช่วยให้รากพืชดูดซึมธาตุอาหารในดินได้ดีที่สุด)
  • ค่าความนำไฟฟ้า (EC) และความเค็ม (Sal):
    • พืชทั่วไป / ผัก / ไม้ผล: EC ไม่ควรเกิน 750 – 1,000 ไมโครโม/ซม. (Sal ≤ 0.50)
    • ข้าวและพืชทนเค็มปานกลาง: EC ไม่ควรเกิน 2,000 ไมโครโม/ซม. (Sal ≤ 1.00) หากเกินกว่านี้ใบจะไหม้ ข้าวเมล็ดลีบ และดินเสื่อมสภาพ
  • ออกซิเจนละลายน้ำ (DO): ≥ 2.00 – 3.00 มก./ลิตร ป้องกันรากพืชเน่าเสีย

🐟 3. การเลี้ยงสัตว์น้ำและปศุสัตว์

  • การเพาะเลี้ยงสัตว์น้ำ (ปลา / กุ้ง):
    • DO (สำคัญที่สุด): ควรอยู่ที่ 4.00 – 5.00 มก./ลิตรขึ้นไป (หากต่ำกว่า 2.00 ปลาจะลอยหัวขาดอากาศตาย)
    • pH: 6.50 – 8.50 (เหมาะสมสุด 7.50 – 8.50)
    • ความเค็ม: ปลาน้ำจืด ≤ 1.00 ก./ล. / สัตว์น้ำกร่อย 5.00 – 25.00 ก./ล.
  • น้ำดื่มสำหรับปศุสัตว์ (โค กระบือ สุกร ไก่): ควรมีค่า TDS ต่ำกว่า 1,000 – 1,300 มก./ลิตร (EC ≤ 2,000) และสะอาดปราศจากน้ำเน่าเสีย

นิยามของแต่ละค่าการตรวจวัด (เข้าใจง่ายสำหรับประชาชนทั่วไป)

1. ค่าความเป็นกรด-ด่าง (pH)

เกณฑ์ปกติ: 6.50 – 8.50 • บอกว่าน้ำเป็นกรดหรือเป็นด่าง หากต่ำกว่า 6.50 น้ำจะค่อนข้างเป็นกรด (อาจระคายเคืองหรือกัดกร่อน) หากสูงกว่า 8.50 จะเป็นด่างมากขึ้น

2. ค่าความนำไฟฟ้า (EC)

เกณฑ์ปกติ: ไม่เกิน 2,000.00 ไมโครโม/ซม. • บอกความสามารถของน้ำในการนำกระแสไฟฟ้า ซึ่งแปรผันตามเกลือแร่และไอออนที่ละลายอยู่ หากสูงมากมักบ่งชี้ว่ามีน้ำกร่อย/น้ำเค็มปน หรือมีสารละลายสูง

3. ค่าความเค็ม (Salinity / Sal)

เกณฑ์ปกติ: ไม่เกิน 1.00 กรัม/ลิตร • บอกระดับความเค็มของน้ำ หากเกิน 1.00 กรัม/ลิตร อาจส่งผลต่อพืชผลทางการเกษตรที่ไวต่อความเค็มและการใช้น้ำอุปโภคบริโภค

4. ค่าออกซิเจนละลายน้ำ (DO)

เกณฑ์ปกติ: ไม่ต่ำกว่า 2.00 มิลลิกรัม/ลิตร • คือปริมาณออกซิเจนที่ละลายอยู่ในน้ำ สัตว์น้ำและสิ่งมีชีวิตในน้ำต้องใช้หายใจ หากต่ำกว่า 2.00 มก./ลิตร แปลว่าออกซิเจนน้อย เสี่ยงต่อสัตว์น้ำและเกิดน้ำเน่าเสียได้ง่าย

5. ค่าของแข็งละลายน้ำ (TDS)

เกณฑ์ปกติ: ไม่เกิน 1,300.00 มิลลิกรัม/ลิตร • คือปริมาณแร่ธาตุ เกลือ และสารอินทรีย์/อนินทรีย์ที่ละลายปนอยู่ในน้ำ หากสูงเกินเกณฑ์น้ำอาจมีรสกร่อยหรือขุ่นมัวเมื่อระเหยแห้ง
